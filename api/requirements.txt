# Dependencies for the Vercel Python serverless function (api/index.py).
#
# Kept HERE and not at the repo root on purpose: a root requirements.txt makes
# Vercel detect the whole repo as a Python backend-framework project, which
# overrides the Vite build (buildCommand -> frontend/dist) declared in
# vercel.json. Next to the entrypoint, @vercel/python still installs it for the
# function while the root stays a plain static/Node build.
#
# Deliberately smaller than backend/requirements.txt: serverless bundles are
# size-capped, and the ingest-only readers are imported lazily inside their
# loader functions, so they are not needed to serve requests over a corpus of
# .txt/.md files.
#
# Add pypdf / python-docx here only if you commit .pdf/.docx specifications
# into backend/data/corpus/ (they are rebuilt on every cold start).
#
# Both LLM SDKs are listed because each is imported lazily inside its own
# client class, so the unused one costs bundle size but never import time.
# Delete whichever provider you are not deploying with to shrink the bundle.
